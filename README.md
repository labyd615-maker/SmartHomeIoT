# Smart Home IoT

OMNeT++ smart-home IoT simulation: network definitions (`.ned`), configuration (`omnetpp.ini`), and analysis files for four experiments.

- `screenshots/` – simulation runs and result charts
- `results/` – experiment data (Excel)
